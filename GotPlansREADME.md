# Got Plans The App
This app allows to the user to add upcoming events and keep track of them.

It will allow the user to keep track of events, update existing ones in case of any change as well as delete them if the event has been cancelled or better yet, if the user feels they no longer wish to attend.

User can register by plugging in their details(name, username, email and password), login using the same registration details and they will be then given access to the dashboard where they will be able to add and track their events.

There is also a "Help" page that explains how the app can be used once the user is logged in.
